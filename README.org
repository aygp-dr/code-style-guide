#+TITLE: code-style-guide
#+AUTHOR: aygp-dr

A babashka CLI tool that enforces coding style rules across polyglot codebases.

** Quick Start

#+begin_src bash
bb style:check -- --dir ./my-project
bb style:check -- --dir ./my-project --format json --severity medium
#+end_src

** Requirements

- [[https://github.com/babashka/babashka][Babashka]] v1.12+

** Development

This repo follows the aygp-dr Clojure standard: =deps.edn= is the canonical
manifest and =bb.edn= provides the tasks. The tool's own commands are
=bb style:check= and =bb style:fix=; plain =bb check= is the repo's own
lint + fmt + test gate.

| Task                    | What it does                          |
|-------------------------+---------------------------------------|
| =bb style:check=        | run the style checker (options as in Quick Start) |
| =bb style:fix=          | the same with =--fix=                 |
| =bb test=               | JVM test suite (=clojure -M:test=)    |
| =bb test:bb=            | the same tests under babashka         |
| =bb lint=               | clj-kondo (fails on errors)           |
| =bb fmt= / =bb fmt:fix= | cljfmt check / fix                    |
| =bb check=              | lint + fmt + test + test:bb (CI runs this) |

*** Specs

Data specs live in =src/code_style_guide/specs.clj=, and each public fn in
=code-style-guide.core= has an =s/fdef= right after its =defn= (see the
[[https://clojure.org/guides/spec][clojure.spec guide]]).
=test/code_style_guide/specs_test.clj= runs =stest/check= over every pure fn.
The unit tests run with instrumentation on, and =clj -M:dev= instruments at the REPL.

** Rules

| Rule | Severity | Fixable | Description |
|------|----------|---------|-------------|
| line-length | low | no | Lines over 120 chars |
| trailing-whitespace | low | yes | Trailing spaces/tabs |
| tabs-not-spaces | medium | yes | Tab indentation |
| consecutive-blank-lines | low | no | Multiple blank lines |
| todo-without-ticket | medium | no | TODOs lacking ticket refs |
| fixme-present | high | no | FIXME comments |
| debug-print | high | no | print/console.log/fmt.Print |
| magic-number | medium | no | Unnamed numeric constants |

** Supported Languages

Python, JavaScript/TypeScript, Go, Java, Ruby, Clojure, Rust, Shell

** Exit Codes

- =0= — clean
- =1= — violations found
- =2= — error
